# Game Store React frontend

A simple React app for managing games with basic CRUD operations.

## Features
- view games
- add games
- edit existing games
- delete games

## Prerequisites
- Node.js
- Game Store .NET API backend

## Setup
1. npm install
2. npm run dev
3. Open http://localhost:5173

## Docket Deployment
Build Docker Image:
docker build -t gamestore-react

## Tech Stack
- React
- Typescript
- Bootstrap
- Vite
- React Router
